# 장 간 함선 밸런스

MOONWAKE의 모든 장(임진왜란, 아르마다, 레판토, 적벽, 트라팔가르)의 함선은 한 전장에서 섞여 싸울 수 있어야 한다: 쟁탈전에서 갤리온 함대 대 판옥선 함대, 대전 모드([design-pvp.md](design-pvp.md))의 물결.

## 모델
1. **역사 수치가 먼저**: 각 함선의 길이·폭·승조원·포 배치·속도는 시대 자료(아르마다: Martin & Parker, Konstam, Kirsch)에서 정하고, 포는 1592년 포의 눈금에 맞춰 환산한다. 기준은 천자총통 520 m. 컬버린 560 m·17파운드, 데미컬버린 480 m, 에스파냐 카뇬 360 m·30파운드 이상이지만 육상 포가라 장전이 느림(단계 합 61초 대 컬버린 28초), 석포·세이커·선회포. `src/sim/catalog.ts`.
2. **값으로 맞춘다**: 성능은 역사대로 두고 **가격(점수)**으로 공정성을 맞춘다. 한 함선의 점수 = 쟁탈전 가격(`src/sim/competitive.ts`의 `COMPETITIVE_UNITS[kind].spec.cost`, `src/sim/points.ts`의 `shipPoints`). 1592년 8척의 가격은 랭크전이 맞춰 둔 값 그대로, 다른 장의 함선은 그 값에 대해 맞춘다. 등급(`tier` 1 소형·2 중형/지원·3 주력·4 대형)은 대전 물결과 UI 묶음용.
3. **잣대는 함대 대 함대**: 같은 장 안의 함선끼리는 일부러 상성이 있다(조선 포열이 일본 도선선을 이김). 그래서 함선 한 종 대 한 종은 50%가 목표가 아니고, **나라 함대 대 나라 함대**를 같은 예산으로 붙였을 때가 기준이다. 목표: 새 장의 나라는 1592년 세 나라가 서로에게 보이는 승률 범위 안에 들어갈 것, 같은 장의 두 나라는 50% 근처.
4. **결정론**: 가격과 새 함선만 바뀌므로 1592년 역사 전투·랭크·일반 쟁탈전 다이제스트(`node scripts/sim-digest.mjs`)는 비트 단위로 같음(확인함). 랭크 로스터(`RANKED_ROSTER`)는 아직 1592년 8척.

## 도구
- `node scripts/balance-competitive.mjs --mode=conquest --seeds=6 --match=england:spain,england:joseon,...` 컴퓨터 대 컴퓨터 쟁탈전(한려·견내량, 양쪽 출발점) — **기준**. `--set=unit.spgalleon.cost=700`로 후보 가격 시험.
- `node scripts/balance-cross.mjs [--kinds] [--md] [--fit]` 탁 트인 바다에서 같은 점수의 함대 결투(나라 함대 + `--kinds`면 함선 쌍). 거점·경제 없이 순수 전투 효율만 봄: 참고용(1592년 나라끼리도 여기서는 한쪽으로 크게 기움).
