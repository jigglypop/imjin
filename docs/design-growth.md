# 장수 성장 설계: 재능 나무와 전리품

계정에 남는 장수 육성(`/generals`). 코드: `src/meta/talents.ts`(나무), `src/meta/loot.ts`(전리품), `src/meta/rules.ts`(규칙), `server/meta.ts`(서버 경로), UI `src/ui/generals/TalentTree.tsx`·`Inventory.tsx`.
캠페인(`src/sim/grand`)의 재능 단계는 그대로이고, 이 문서는 계정 쪽만 다룬다. 전투에는 배 계수(ShipMods)만 들어가고 `applyGenerals`를 거치며, 랭크전과 온라인 전투에는 적용되지 않는다.

## 목표
- 레벨이 오를 때마다 고를 것이 있고, 몇 레벨마다 눈에 보이는 이정표가 있다.
- 핵심 재능 셋 중 하나만 고를 수 있어 장수마다 빌드가 갈린다.
- 장수의 역사적 특성과 맞는 재능을 찍으면 더 세진다(공명).
- 익히기 전에 바뀌는 수치를 미리 보여 준다. 초기화(리스펙)는 처음 한 번 무료, 그다음부터는 비용을 받는다.
- 전투에서 칼·창·활·방구·등채·병서·인장을 줍고, 장착하고, 다시 벼리고, 분해한다.

## 재능 나무
- 장수마다 가지 셋. 캠페인 나무의 가지(포술·통솔·항해·백병 중 2–3개)를 그대로 쓰고, 둘뿐이면 고유 특성이 올리는 능력 쪽 가지를 셋째로 더한다(명중·장전·화공 → 포술, 사기 → 통솔, 속도·선회 → 항해, 백병·방어 → 백병).
- 가지마다 5단:
  - 1단: 두 갈래 시작 재능(각 3단계)
  - 2단: 1개(2단계)
  - 3단: 둘 중 고르기(각 1단계)
  - 4단: 1개(3단계)
  - 5단: 핵심 재능
- 단 개방: 그 가지에 쓴 점수 2/4/6/9점. 핵심 재능은 10레벨부터.
- 핵심 재능(셋 중 하나만, 장점과 대가가 함께 있음):
  - 포술 「총통 포진」: 장전 +8%, 명중 +5%, 백병 −8%
  - 통솔 「필사즉생」: 사기 +12%, 방어 +5%, 속도 −5%
  - 항해 「조류 장악」: 속도 +7%, 선회 +10%, 방어 −4%
  - 백병 「육박 돌격」: 백병 +15%, 사기 +4%, 명중 −6%
- 비기: 장수 고유의 마지막 재능(캠페인 비기의 수치를 그대로 씀). 12레벨이 되고 재능 점수 8점을 쓴 뒤에 익힌다.
- 공명: 고유 특성이 올리는 능력을 함께 올리는 재능은 그 몫이 50% 더 커진다. 예: 이순신(학익진: 명중·사기)의 정조준은 단계마다 +1.5%가 아니라 +2.25%. 나무에서는 청록 점으로 표시한다.
- 점수: 레벨마다 1점, 이정표 보너스는 5·8·10·15레벨에 +1, 20레벨에 +2. 20레벨이면 25점이고, 가지 하나를 채우는 데 13점, 핵심 재능·비기에 각 1점이 든다. 그래서 두 가지를 깊게 가거나 세 가지를 얕게 고르게 된다.
- 레벨: 최고 20(이전 10). 필요 경험치는 그대로 `50·L·(L−1)`.

### 이정표
| 레벨 | 이름 | 보상 |
|---|---|---|
| 3 | 초급 무관 | 2단 개방이 가능해짐 |
| 5 | 중견 장수 | +1점 |

| 10 | 명장 | 핵심 재능 개방, +1점 |

### 상한
- 재능을 모두 더해도 한 능력에 +32%, −10%를 넘지 않는다(`TALENT_CAP`).
- 특성·재능·갑옷·장비를 모두 곱한 장수 계수는 능력마다 0.85–1.5 사이(`GENERAL_CAP`).
- 갑옷 한 벌은 능력마다 최대 1.12, 전리품 한 점은 최대 1.10.

### 초기화
첫 초기화는 무료이고, 그다음부터는 100 × 레벨 엽전. 핵심 재능을 바꾸는 유일한 방법이다.

### v1 프로필 이전
예전 `skills`(캠페인 단계)는 읽을 때 버리고 점수는 모두 돌려준다. 저장된 `talents`는 읽을 때 같은 규칙(단 개방, 레벨 점수, 단 순서)으로 다시 검증한다.

## 전리품
- 자리 다섯: 무기 / 방구(첨주·견철·호완·갑상) / 지휘구(등채·지휘봉·군선·나각·신전) / 병서(손자병법·오자·기효신서·육도삼략·병학지남) / 인장(병부·장군인·마패·교서 어보).
- 무기는 나라마다 6종이고 기존 3D 무기와 같은 id를 쓴다. 장착하면 장수 모형 손에 그 무기가 쥐어진다. 다른 나라 무기는 장착할 수 없다.
- 등급: 일반 / 고급 / 희귀 / 영웅 / 전설.
  - 기본 확률: 56% / 28% / 12% / 3.4% / 0.6%
  - 별과 격침 수가 높은 등급의 가중치를 올린다(별마다 +15%, 격침마다 +1%, 격침은 최대 30척까지).
  - 능력치 점수: 1–3 / 2–5 / 4–7 / 6–9 / 8–12
  - 특수 능력: 0 / 0–1 / 1 / 1–2 / 2–3
- 능력치는 갑옷과 같은 힘·민첩·지능·활력과 특수 능력(`affixes.ts`)이고, 같은 난수기로 굴린다. 종류마다 잘 붙는 능력치가 있다(활은 지능·민첩, 병서는 지능, 방구는 활력).
- 드롭 수:
  - 승리: 1개, 35% 확률로 2개
  - 무승부: 50% 확률로 1개
  - 패배: 20% 확률로 1개
  - 그 전투·진영의 첫 승리: 희귀 이상 1개 추가
- 분해하면 엽전 20 / 60 / 180 / 500 / 1500. 다시 벼리기(같은 종류·등급으로 능력치를 새로 굴림)는 60 / 150 / 400 / 1000 / 2500.

### 서버 권위와 검증
- 드롭은 서버의 전투 종료 경로(`/api/meta/battle/finish`, 서버가 돌린 전투는 `payServerBattle`)에서만 생긴다. 페이지가 보낸 물건, 시드, 프로필 전리품은 받지 않는다(가져오기에서도 버림).
- 드롭 = `hash(계정id : drop : 드롭카운터)`, 물건 능력치 = `hash(계정id : item : uid : 벼린 횟수)`. 계정 id와 카운터만 알면 누구나 같은 결과를 다시 계산할 수 있고, 저장된 시드는 읽을 때 다시 계산한다.
- 남용 방지:
  - 서버가 볼 수 없는 싱글 전투의 드롭은 하루 15개까지.
  - 가방은 80칸이고, 넘친 드롭은 분해 값으로 엽전에 들어간다.
  - 기존 장치(티켓 1회, 실제 시간 대비 전투 시간, 격침 수 검증, 시간당 30회 시작 제한)도 그대로 적용된다.
- 원장: 물건이 생기거나 사라질 때마다 `ledger`에 kind `item`, ±1, item `uid:종류:등급`, 사유(battle/salvage…)를 남긴다. 추가만 되는 기록이라 감사에 쓸 수 있다.

## 운영 DB
새 테이블이나 열은 없다. 전리품과 재능은 `profiles.data.meta` JSON(프로필 v2)에, 이력은 기존 `ledger`에 쌓인다. 따라서 운영 RDS 마이그레이션이 필요 없고 스키마 버전은 1 그대로다. v1 프로필은 읽을 때 자동으로 이전된다.

## 그림
- 전리품 아이콘 18종(방구 4, 지휘구 5, 병서 5, 인장 4)은 `public/ui/items/*.webp`(128px)에 있다. Gemini 이미지 모델로 환도 무기 카드를 스타일 참조 삼아 만들었고, 원본과 출처는 `assets-src/item-icons-2026-10-17/`에 있다. 다시 만들 때는 `node --env-file=.env scripts/item-icons.mjs <id>`.
- 무기 18종은 기존 `public/ui/weapons/*.webp`를 쓴다. 등급 테두리는 CSS가 그린다.
- 재능 노드는 한자 두 글자로 표시한다. 문양 그림은 선택 사항이다.
