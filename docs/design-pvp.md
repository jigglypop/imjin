# 대전 설계: 해상 거점전 (MOBA-lite)

모든 장(임진왜란, 아르마다, 레판토, 트라팔가르)에 공통인 실시간 대전 모드. 캠페인은 장수 육성(세력 캠페인 + 장수 성장), 대전은 이 모드다.

## 한 판의 규칙
- 지도: 두 진영의 **본영**(항구 요새)이 양 끝에 있고, 그 사이를 **수로 2–3개**(레인: 해안 수로, 외해, 섬 사이 수로)가 잇는다. 레인마다 **전진 기지**(포대 진지, 봉수대 섬) 2개씩.
- **물결(웨이브)**: 각 진영의 살아 있는 기지(본영·전진 기지)가 45초마다 정해진 함선 묶음을 자동으로 띄운다(예: 임진 조선 = 판옥선 1 + 협선 2, 아르마다 영국 = 경갤리온 1 + 핀네이스 2). 묶음은 레인을 따라 적 기지로 전진하고, 만난 적과 싸운다. 시간이 갈수록 묶음이 커진다(8분, 16분에 단계 상승).
- **기지 파괴 = 생산 중단**: 전진 기지는 체력이 있고 자기 포대로 방어한다. 부서지면 그 기지에서 나오던 물결이 멈추고, 그 레인의 적 물결이 한 단계 강해진다(상대 쪽 "슈퍼 물결"). 본영이 부서지면 패배.
- **플레이어의 몫**: 각 플레이어는 자기 **장수 기함**(영웅 유닛: 지휘 반경, 사망 시 30–60초 뒤 본영에서 부활) 하나와, 물결 중 원하는 함선을 **지휘권으로 끌어오기**(최대 8척)로 직접 명령한다. 지휘하지 않는 함선은 레인 AI(기존 `Strategist`/`tactician`의 레인 추종 모드)로 움직인다.
- **자원**: 격침·기지 피해로 얻는 군공(점수)으로 기함 강화(장수 기술 3개 중 선택)와 다음 물결에 함선 1척 추가 구매. 구매 가격은 아래의 교차 장 점수(`points`)를 쓴다.
- 승리: 상대 본영 파괴, 또는 25분에 남은 기지 체력 합이 많은 쪽.

## 시뮬레이션과 서버
- 새 규칙은 `src/sim/lanes.ts`의 `Lanes implements BattleRules`(쟁탈전의 `Conquest`와 같은 자리). 물결 타이머, 기지 체력, 레인 경로점 모두 전투의 시드 RNG와 고정 스텝 시간만 사용 → 결정론 유지, 서버(`server/battles.ts`)가 그대로 권위 실행.
- 기존 전투 규칙(`battle.ts`, `depth.ts`)은 건드리지 않음: 물결 함선은 `Battle.addShip` + `order: {type:'follow'}`/경로 이동으로만 만든다. 그래서 임진왜란 역사 전투·랭크 쟁탈전 다이제스트(`scripts/sim-digest.mjs`)는 그대로.
- 프로토콜(`src/net/protocol.ts`): 기지 상태(체력, 다음 물결까지 초)와 함선의 `lane`, `commanded` 필드 추가 — 클래식 쟁탈전 스냅샷과는 별도 블록.
- 랭크: 처음에는 일반 대전으로만 열고, 밸런스 하네스(아래)가 장 간 대진 50±5%를 통과한 뒤 별도 랭크 큐(`ranked-lanes`)로. 기존 랭크 기록과 섞지 않음.
- 장수 성장: 계정의 장수 효과(`applyGenerals`)는 랭크에서 꺼짐(공정성), 일반 대전에서는 기함에만 적용.

## 장 간 밸런스와의 연결
- 모든 장의 함선은 `src/sim/points.ts`의 **점수**(`points`)와 **등급**(tier 1–4)을 가진다. 물결 묶음은 진영마다 같은 점수 합으로 구성된다(예: 단계 1 = 600점). 그래서 갤리온 함대와 판옥선 함대가 붙어도 같은 비용끼리 싸운다.
- 점수는 `scripts/balance-cross.mjs`(같은 점수의 함대끼리 결정론 대결, 승률 50% 목표)로 맞춘다: 모델은 [balance-cross.md](balance-cross.md).

## 시제품 계획
1. `lanes.ts` 규칙 + 대칭 섬 지도 1개(기존 `symmetric` 지형), 컴퓨터 대 컴퓨터로 `check-stalemate`처럼 반드시 끝나는지 검사.
2. 클라이언트: 쟁탈전 HUD를 재사용해 기지 체력·물결 타이머, 함선 끌어오기 명령.
3. 서버 방 종류 `lanes` + 빠른 매칭, 브라우저 두 개로 `mp-browser.mjs` 스모크.
4. 장마다 물결 묶음과 기지 포대 정의(장 레지스트리 `src/chapters`의 `pvp` 항목).
